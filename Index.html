Citak Coin

Citak Coin is an educational meme cryptocurrency featuring a black cat in a wizard hat. It demonstrates how a crypto token can be created on Binance Smart Chain (BSC) and is meant for learning and fun, not for investment.

This project combines the magic of blockchain with a playful theme to engage and educate newcomers about token development, smart contracts, and crypto communities.

Tokenomics

  • Total Supply: 1,000,000,000 CITAK
  • Blockchain: Binance Smart Chain (BEP-20 Token)
  • Symbol: CITAK
  • Decimals: 18

The initial supply of CITAK is minted to the project creator's wallet. Distribution is planned as follows:

  • 50% – Community rewards and airdrops for educational participation
  • 25% – Project development and future enhancements
  • 15% – Initial liquidity and ecosystem fund
  • 10% – Team and educational partners

Note: Citak Coin is for educational purposes, so these allocations are hypothetical and for demonstration.

Roadmap

  1. Q1 2025: Project concept created. Initial code (smart contract, website, docs) drafted.
  2. Q2 2025: Smart contract developed and tested on testnet. Launch of the website and a draft whitepaper.
  3. Q3 2025: Token deployed on BSC Testnet for demonstration. Website published. Community feedback gathered.
  4. Q4 2025: Educational campaigns and testnet airdrops. Engage the community, refine documentation.
  5. Future: Consider mainnet launch for a broader educational initiative, add new features (e.g., NFTs, dApp integration).
